# birthday · Xaviayou 的生日宇宙

三个完整、独立的 Three.js 生日贺卡网页，纯色奶油粉背景。图片、音乐和程序均内嵌，无需外部 CDN。

- `orbit.html`：第一版，环绕版。
- `spine.html`：第二版，紧贴星星中轴展开。
- `circle.html`：第三版，六张图片紧邻围成一圈，星星不在中央。
- `index.html`：三版导航页。

## GitHub Pages

目标仓库：`Derick-DD/birthday`。三版网页位于仓库根目录，使用下面的设置发布。

将以上文件和 `.nojekyll` 放到仓库根目录。进入 Settings → Pages，将 Source 设为 Deploy from a branch，Branch 设为 main，文件夹设为 / (root)，然后保存。

手机点击“开启贺卡”或“播放音乐”。部分聊天软件的文件预览不执行脚本，请在浏览器中打开。

网站公开可访问意味着照片和祝福也公开。GitHub Pages 的网络可达性取决于访问网络，不能保证所有地区无需 VPN。
